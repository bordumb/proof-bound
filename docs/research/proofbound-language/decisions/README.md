# Proofbound language research decisions

[Programme dashboard](../README.md)

Research decisions select a direction without creating a production contract.
They cite experiment and synthesis evidence, name deferred alternatives, and
include explicit review triggers. Production commitments belong in `docs/adr/`
and normative behavior belongs in `docs/specs/`.
