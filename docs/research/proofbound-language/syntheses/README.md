# Proofbound language research syntheses

[Programme dashboard](../README.md)

Syntheses join immutable experiment results across a single research question.
They do not change an experiment's decision and do not define production
behavior. Each synthesis must link its source experiments, preserve negative
and unanswered results, and state the scope of every comparison.

## Available syntheses

- [Cross-platform enforcement](cross-platform-enforcement.md) — compares the
  bounded macOS, Linux, and Windows execution results and derives the portable
  platform contract.
