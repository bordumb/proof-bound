# Assurance records

This directory contains reviewed, committed inputs about Proofbound's own
assurance boundary. Generated receipts and caches live under `.proofbound/` and
are never sources of truth for manifests.

The reference audit records full revisions and explicitly preserves Matrix
Math's current local-clone durability caveat. A future sealed archive may close
that caveat only by adding its content identity; the existing record must not be
silently rewritten as though durable retrieval had always existed.
