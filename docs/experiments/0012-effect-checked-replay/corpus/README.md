# Experiment 0012 corpus

[`CONTRACT.md`](CONTRACT.md) freezes normalization, authority, execution,
trace, invalidation, and metric semantics. `fixtures/` contains the complete
small reviewed input tree. `plans.json` contains six closed plans,
`enforcement.json` contains the sole synthetic external-enforcement receipt,
`attacks.json` fixes all 23 registered attacks, and `expected.json` binds the
file, plan, and route-output identities before either implementation.

The fixtures resemble the roles of current Proofbound mutation and Python
distribution routes; they are not observations from those production adapters.

The corpus deliberately does not contain an executable sandbox. Its external
enforcement receipt is a typed control used to test binding and honesty; it is
not evidence that the named synthetic mechanism exists on the host.
