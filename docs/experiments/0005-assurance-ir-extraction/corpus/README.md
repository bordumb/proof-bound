# Experiment 0005 corpus

[Experiment registration](../README.md) ·
[Programme corpus](../../../research/proofbound-language/corpus.md)

This directory will index the exact records selected from the programme corpus
for semantic projection and adversarial testing. Before execution, each case
must name:

- stable case ID;
- subject or fixture path;
- Git and record identity;
- evidence family;
- expected current status and publication result;
- selected projection fields;
- positive or adversarial role; and
- any toolchain needed to regenerate it.

Large or external subjects are referenced by identity rather than copied here.
