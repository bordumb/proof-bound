# Public audits

Publishable claim-ledger audits of third-party software — the outward-facing
track. Each audit graduates from an experiment in
[docs/experiments/](../experiments/README.md): the raw record (journal,
findings, divergences) stays there; what lives here is the polished report a
maintainer or reader is meant to see, with every status backed by receipts.

Audit reports obey the same rules as any Proofbound output: faceted statuses,
enumerated assumptions, a mandatory "not proved / out of scope" section, and
no aggregate scores.
